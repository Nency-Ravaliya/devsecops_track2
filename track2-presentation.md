# DevSecOps Assessment Project

## Multi-Cloud Platform Security

---

# Project Goal

- Review the multi-cloud platform setup
- Identify security gaps in platform and infrastructure
- Design a secure and scalable architecture
- Build security checks into the delivery process

---

# Key Findings

- Review covered platform security risks across cloud workloads
- Major issues included IAM misconfiguration, weak network controls, and insecure configuration
- The project focused on reducing attack surface and improving governance
- Security issues were prioritized based on business impact and operational risk

---

# Platform Security Controls

- IAM and access control review
- Policy and guardrail design
- Pipeline security checks and validation
- Secret scanning and vulnerability management
- Runtime detection and incident response planning

---

# Zero-Trust and Network Design

- Least privilege access model
- Network segmentation and deny-by-default posture
- Clear separation of workloads and trust boundaries
- Protection for lateral movement and privilege escalation

---

# Architecture and Compliance

- High-level and low-level architecture design
- Threat model and risk assessment
- Compliance mapping and control evidence
- Resilience and disaster recovery planning

---

# Final Summary

- The project shows a full platform security lifecycle
- It combines review, prevention, detection, and governance
- The goal is to build a practical and production-ready DevSecOps model

### Closing
My objective was to build a secure, scalable, and enterprise-ready platform security solution with security integrated into the whole process.
